# 🎬 Movie Search & Favorite Web App

## 📌 Giới thiệu

**Movie Search & Favorite Web App** là một dự án frontend giúp người dùng tìm kiếm phim từ API công khai và lưu lại danh sách phim yêu thích ngay trên trình duyệt.

Dự án được xây dựng nhằm **luyện tập và củng cố toàn bộ kiến thức Frontend JavaScript cốt lõi**, làm nền tảng để học và chuyển sang **React JS** và **Next.js** sau này.

---

## 🎯 Mục tiêu dự án

* Hiểu rõ cách **Frontend JavaScript hoạt động trong thực tế**
* Áp dụng kiến thức:

  * HTML semantic
  * CSS layout cơ bản
  * JavaScript cơ bản & DOM
  * Bất đồng bộ với `fetch`, `async/await`
* Làm quen với tư duy xây dựng **web app có dữ liệu thật**
* Tạo một demo project đúng chuẩn **Frontend Intern**

---

## 🧠 Kiến thức áp dụng trong dự án

* HTML5 (semantic structure)
* CSS3 (layout, responsive cơ bản)
* JavaScript (ES6+)

  * Biến, function, array, object
  * DOM manipulation & Event handling
  * Asynchronous JavaScript (`fetch`, `async/await`)
  * Xử lý lỗi (error handling)
  * `localStorage`

---

## ⚙️ Chức năng chính

### 🔍 Tìm kiếm phim

* Nhập tên phim
* Gọi API để lấy dữ liệu
* Hiển thị danh sách phim phù hợp

### 🧱 Hiển thị danh sách phim

* Poster phim
* Tên phim
* Năm phát hành

### ⭐ Quản lý phim yêu thích

* Thêm phim vào danh sách yêu thích
* Xóa phim khỏi danh sách yêu thích
* Lưu dữ liệu bằng `localStorage`

### ⏳ Trạng thái ứng dụng

* Hiển thị loading khi đang gọi API
* Thông báo khi không có kết quả
* Thông báo lỗi khi API gặp sự cố
